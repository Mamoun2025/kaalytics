Comment ça marche

Pour Odoo : Connexion native via XML-RPC et accès direct PostgreSQL. Aucun API external, pas de latence, données en temps réel.

Pour SAP, Sage, Dynamics : Architecture REST extensible. Nous connectons ce que vos systèmes exposent, et ce qu'ils ne le font pas non plus (access direct base si nécessaire et sécurisé).

Pour systèmes legacy (AS400, Access, DOS) : Import CSV, connexion FTP, API propriétaire, ou lecture directe de fichiers plats. Aucun système n'est trop vieux pour être connecté.

Déploiement : Serveur VPS dédié avec isolation multi-tenant. Chaque filiale voit ses propres données. Redondance, monitoring, alertes 24/7.

Scénario illustratif : une entreprise de distribution

Prenons une PME de distribution avec 3 sites et un Odoo legacy. Aujourd'hui :

  • Les commerciaux envoient des bons de commande en PDF
  • Une personne les rentre manuellement dans Odoo
  • Les ops impriment et traitent les commandes en papier
  • Pas de visibilité cross-site sur le stock

Avec ERP Connect :

  • Jour 1-2 : Dashboard de suivi des commandes. Lecture en temps réel depuis Odoo.
  • Jour 5-10 : Interface de saisie des commandes qui écrit dans Odoo. Zéro ressaisie.
  • Jour 15-20 : Vue consolidée stock cross-site. Réallocation possible d'un clic.
  • Jour 25-30 : Modules métier (suggestions de destockage, alertes prix, relance impayés).

Résultat : 10 heures d'administration économisées par semaine, zéro double-saisie, visibilité temps réel. Et Odoo n'a pas changé d'une ligne.

Limites et prérequis

Ce qu'on ne peut pas faire : Modifier votre ERP ou ses workflows. ERP Connect se branche *sur* vous, pas *dans* vous. Si vous avez besoin de développements custom dans Odoo, c'est un autre sujet (que nous faisons aussi).

Prérequis : Accès API ou base de données (lecture), crédentials, documentation des formats de données. Pour Odoo, accès PostgreSQL si possible (plus rapide et plus sûr qu'XML-RPC).

Pour les systèmes legacy sans API : nous connectons via fichiers plats (CSV, Excel) ou FTP. Un peu moins rapide en temps réel, mais ça marche. Le tradeoff : vous gérez les extraits, nous branchons la suite intelligemment.

Garanties : RTO < 5 min (recovery time objective). RPO < 30 sec (recovery point objective). Audit de sécurité externe possible. Chiffrement bout-en-bout optionnel.

Questions fréquentes

Les questions les plus posées par nos clients avant de se lancer avec ERP Connect. Si votre question n'y est pas, contactez-nous directement par WhatsApp.

Faut-il modifier notre ERP pour connecter ERP Connect ?

Non. ERP Connect se branche *sur* vos données, pas *dans* vos données. Zéro modification de code, zéro risque pour vos workflows existants. Votre ERP continue exactement comme avant, sans interruption. C'est la promesse fondamentale : innovation sans disruption.

Combien de temps pour mettre en production ?

Entre 2 et 4 semaines pour les bases (Odoo), jusqu'à 8 semaines pour les systèmes complexes (SAP, Dynamics). Test complet inclus, avec migration progressive par module.

Comment ça se passe si votre plateforme est down ?

Votre ERP continue de fonctionner normalement. C'est juste que les dashboards et modules externes seront indisponibles. Les workflows métier ne sont jamais bloqués par notre platform. Redondance et failover automatique pour < 5min RTO.

Quel est le coût d'une connexion supplémentaire (2e ERP) ?

Cela dépend du système. Odoo vers Odoo : 2-3 jours. Odoo vers SAP : 3-5 jours. Consultez-nous pour une étude, toujours moins cher qu'une intégration manuelle ou qu'un ETL fourni standard.

Nos données restent sécurisées ?

Oui. Chiffrement en transit (TLS 1.3), au repos, et dans les logs. Vos données ne quittent jamais votre zone de couverture (VPS chez OVH, AWS ou on-premise selon votre choix). Audit de sécurité tiers disponible.
